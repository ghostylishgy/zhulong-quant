# 烛龙开发感想：L4 不应消灭风险，而应判断哪些风险值得承担

日期：2026-08-27

## 背景

烛龙经过近半年的开发和观察，已经形成从 L1 候选召回、L1.5 形态门控、L2 事实解释、L3 条件审计，到 L4 综合裁决以及新闻、市场潮汐、账户资格和 T+1 入场安全门的完整链路。

近期系统长期缺少最终入选标的。复盘表明，原因并不只在单一模块：L1.5 的成熟趋势门、L3 的确定性分桶都会压缩候选，但 L4 也存在独立的风险厌恶倾向。即使一只股票已经通过前置筛选，L4 仍容易把“存在风险”理解成“资格不足”，使 HOLD 成为默认落点。

## 今天形成的认识

旧 L4 长期询问的是：

> 这只股票是否足够安全？

但股票不可能没有风险。更合适的问题应该是：

> 在 L1 至 L3 已完成筛选的前提下，这只股票的机会是否真实，剩余风险是否明确、可管理，并值得进入下一道执行安全门？

L4 的职责不应是再次消灭所有风险，而应识别风险的性质：

- 不可承受的硬风险，应当 VETO。
- 足以改变投资逻辑、但尚未查清的关键风险，应当 HOLD。
- 已被识别、能够通过价格、仓位、期限和失效条件管理的普通交易风险，不应自动否决，可以授予继续验证资格。

PASS 仍然不是买入建议。它只表示候选可以继续进入新闻复核、市场潮汐、账户资格和 T+1 入场门。真正的安全来自多层职责分工，而不是让每一层都重复执行最严格的否决。

## 对“积极”的理解

积极不等于要求模型尽量找理由通过，也不等于为了增加标的而降低事实标准。那会从风险厌恶滑向确认偏误。

更合理的积极，是让举证责任保持对称：

- Bull 必须说明机会由哪些权威证据支持。
- Bear 必须说明风险为什么足以阻止继续验证。
- 缺少额外利好证据，不等于存在否决性风险。
- 存在波动、高换手或资金分歧，也不必然等于资格不足。
- 模型应评价机会与风险是否匹配，而不只是累计风险数量。

这意味着新 L4 不应成为一道更宽松的门，而应成为一道更懂得风险定价的门。

## 关于模型的阶段性判断

后续 L4 仍优先考虑国产云模型。DeepSeek、Kimi、千问和 GLM 在成本、中文表达、A 股术语和本地政策语境方面具有现实优势，适合烛龙这种证据已结构化、候选数量有限的盘后审计任务。

但模型品牌不能预先决定角色。Kimi 是否更适合机会论证、DeepSeek 是否更适合反证、千问是否更适合结构化裁决、GLM 是否更适合独立复核，都只能作为待验证假设。后续应使用烛龙自己的历史案例和前向样本评价，而不是依赖通用排行榜。

新模型也不能简单套用旧提示词。旧提示词中的“最高法院”“资格安全”“证据不足即 HOLD”等表达，可能系统性强化保守倾向。下一轮设计应在不放松证据纪律的前提下，重新定义 L4 的角色、举证责任和风险接受边界。

## 暂不改变的边界

本次只是开发反思，不是生产规则，也不构成策略授权。当前仍保持：

- 冻结证据链和时间截面。
- 禁止模型创造输入外事实。
- 禁止把 PASS 解释为买入。
- 新闻、潮汐、账户资格和 T+1 入场门继续独立工作。
- 不因希望增加候选而设定目标 PASS 数量。
- 任何提示词和模型调整都必须经过历史重放与前向观察。

## 留给未来复盘的问题

未来重新设计 L4 时，应继续回答：

1. 哪些风险是真正不可承受的硬风险？
2. 哪些风险只是股票交易必然存在、但可以通过计划管理的风险？
3. L4 如何识别“风险补偿后的机会”，而不是只计算风险总量？
4. 如何避免 L1 至 L3 和 L4 对同一风险重复惩罚？
5. 国产模型在相同证据下，是否能稳定区分普通风险、关键不确定性和硬否决？
6. 新提示词是否提高了机会识别能力，同时没有扩大错误 PASS 的尾部损失？

今天最值得保留的一句话是：

> 烛龙不是要变得胆大，而是要让谨慎开始有层次。
